# EstacionaFacil
PROJETO DA DISCIPLINA DE ENGENHARIA DE SOFTWARE

Sobre o projeto: Projeto desenvolvido para a disciplina de Engenharia de Software do curso de Análise e Desenvolvimento de Sistemas da Universidade de Taubaté.
Objetivo: Desenvolver um sistema capaz de analisar a satisfação dos clientes de um estacionamento, classificando as avaliações e apresentando indicadores para auxiliar na tomada de decisões.

Tecnologias utilizadas:
Java;
NetBeans;
Java Swing;
MySQL;
HeidiSQL;
GitHub.

Funcionalidades propostas:
Cadastro de avaliações;
Classificação automática de comentários;
Análise de satisfação;
Painel gerencial;
Emissão de alertas;
Filtragem de avaliações.
