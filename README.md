# EstacionaFácil

*Sobre o projeto:* Projeto desenvolvido para a disciplina de Engenharia de Software do curso de Análise e Desenvolvimento de Sistemas da Universidade de Taubaté (UNITAU).

*Objetivo:* Desenvolver um sistema de análise de satisfação dos clientes de um estacionamento, facilitando a identificação de problemas nos serviços oferecidos e auxiliando os gestores na tomada de decisões.

*Funcionalidades:* Cadastro de avaliações dos clientes, Classificação automática dos comentários por palavras-chave, Identificação de avaliações positivas, negativas e neutras, Painel de indicadores de satisfação, Filtragem de avaliações, Alertas de baixa satisfação e Armazenamento de informações no banco de dados.

*Tecnologias utilizadas:* Java, Java Swing, NetBeans, Maven, MySQL, HeidiSQL e GitHub.

*Organização do repositório:*

-documentacao: requisitos do projeto e manuais.

-diagramas: diagramas UML e modelagem do banco de dados.

-banco-de-dados: script SQL.

-sistema: código-fonte do projeto.

-testes: planejamento dos testes de software.
